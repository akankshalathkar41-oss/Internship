# Akanksha Lathkar — Portfolio

This is a personal portfolio website introducing Akanksha Lathkar, sharing her skills, and providing contact and social links.

## Open the website

Keep the project files and `images` folder together. Open `Index.html` in a web browser to view the portfolio. No installation or build step is needed.

## Project files

- `Index.html` — the page content and structure.
- `style.css` — colors, layout, fonts, responsive design, and interactive states.
- `script.js` — theme switching, skill filters, contact form validation, and other page behavior.
- `images/image1.jpeg` — profile photo shown in the About section.

## Website features

- About, Skills, and Contact sections with in-page navigation.
- Responsive layout for desktop and mobile screens.
- Dark and light themes; the selected theme is saved in the browser.
- Filters for all skills, technical skills, or soft skills.
- Contact form checks the name, email, and message and displays helpful errors.
- Live message character count, up to 500 characters.
- Footer year updates automatically.

## Contact form note

The form validates entries and displays a confirmation message, but it does not send messages. To receive messages, connect the form to a backend or a form service.

## Editing the portfolio

- Update the text, skills, navigation, or social links in `Index.html`.
- Change the appearance in `style.css`.
- Change the interactive behavior in `script.js`.
- Replace the profile photo or update its path in `Index.html`.
